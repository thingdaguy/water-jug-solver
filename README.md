# Water Jug Solver

Ứng dụng giải bài toán đong nước 3 bình bằng các thuật toán tìm kiếm trong Trí tuệ Nhân tạo và mô phỏng trực quan bằng giao diện Tkinter.

## Thuật toán hỗ trợ

- BFS (Breadth-First Search)
- DFS (Depth-First Search)
- UCS (Uniform Cost Search)
- Greedy Best-First Search
- A* Search

## Chức năng

- Nhập dung tích 3 bình và lượng nước mục tiêu.
- Chạy và so sánh các thuật toán tìm kiếm.
- Mô phỏng quá trình rót nước bằng animation.
- Hiển thị số trạng thái đã duyệt và thời gian thực thi.
- Trực quan hóa đồ thị tìm kiếm.

## Cách chạy

Yêu cầu:

- Python 3.10+

Chạy chương trình:

```bash
python main.py
```

hoặc:

```bash
python3 main.py
```
